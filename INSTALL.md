🎬 AE Assistant — установка
===========================

**AE Assistant** — панель для After Effects: ИИ-чат и быстрые анимации одной кнопкой.
Ставится за минуту, без ручного копирования папок и правки реестра.

🧰 Что нужно
------------

*   **Windows 10 или 11**
*   **After Effects 2022 (22.0) или новее**
*   Права администратора **не нужны** — всё ставится в твою учётную запись

🚀 Установка
------------

1.  Скачай `AE-Assistant-<версия>-win.zip` из [последнего релиза](https://github.com/Bonecrypto/bone.aep-ae-assistant/releases/latest).
2.  **Распакуй архив целиком** — правой кнопкой → **Извлечь все…**
3.  **Закрой After Effects**, если он открыт.
4.  Запусти `install.cmd` в распакованной папке. Он включит режим разработчика CEP и скопирует панель куда нужно.
5.  Открой After Effects → **Window → Extensions → AE Assistant**.

> **Windows ругается на install.cmd?** Файл не подписан, поэтому SmartScreen может предупредить.
> Нажми **Подробнее → Выполнить в любом случае**. Скрипт ничего не скачивает и меняет только две вещи — они перечислены ниже.

✅ Проверь, что работает
------------------------

1.  Создай композицию, добавь пару слоёв и **выдели их**.
2.  Поставь указатель времени туда, где слой должен оказаться на месте.
3.  Вкладка ✨ **Анимация** → плитка **«Влёт слева»** → на позиции появятся 2 ключа с плавным торможением.
4.  **Ctrl+Z** один раз — и всё отменится.

Внизу панели — строка статуса: там написано, что сделано или что пошло не так.
**Ctrl+K** — поиск по всем действиям панели.

🤖 Чат с ИИ
-----------

Шестерёнка → выбери модель:

| Модель | Что нужно |
|---|---|
| **OpenRouter** | ключ с [openrouter.ai/keys](https://openrouter.ai/keys) |
| **Gemini** | ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| **Ollama** | установленная [Ollama](https://ollama.com) и модель, например `ollama pull qwen2.5:7b` |

Ключ хранится только в панели на твоём компьютере. Перед каждым изменением проекта чат спрашивает подтверждение.

🛠 Если панель не появилась
---------------------------

| Что видишь | Что сделать |
|---|---|
| Нет пункта в **Window → Extensions** | Перезапусти AE полностью. Проверь, что версия AE — 2022 или новее |
| Панель белая / пустая | Запусти `install.cmd` ещё раз при **закрытом** AE |
| «Скрипт панели не загрузился в AE» | Закрой и снова открой панель |
| «Откройте композицию…» | Кликни по таймлайну нужной композиции и повтори |

Отладка для разработчиков: при открытой панели зайди в Chrome на `http://localhost:8860`.

🔍 Что меняет установщик
------------------------

*   Копирует панель в `%APPDATA%\Adobe\CEP\extensions\com.aeassistant.panel`
*   Ставит `PlayerDebugMode = 1` в `HKCU\Software\Adobe\CSXS.11`, `.12`, `.13` — так AE разрешает неподписанные панели

Больше ничего: ни служб, ни автозапуска, ни файлов вне этой папки.

🔄 Обновления
-------------

Панель сама проверяет новые версии при запуске — сверху появится кнопка **«Обновление …»**.
Шестерёнка → **Обновления** → **Обновить**: панель скачает новую версию и перезапустится.
Там же можно **откатиться** на прошлую сборку.

🗑 Удаление
-----------

Запусти `uninstall.cmd` — он удалит папку панели. Режим разработчика CEP остаётся включённым, потому что им могут пользоваться другие панели.

### 👩‍💻 Установка из исходников (для разработки)

Нужен Node.js 20+.

```bash
npm install
```
```bash
npm run build
```
```bash
npm run install:dev
```

`npm run package` собирает тот же архив для релиза: `dist/release/AE-Assistant-<версия>-win.zip`.
